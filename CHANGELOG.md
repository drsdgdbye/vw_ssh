# Changelog

## 0.1.0

- Standalone pipx package for Linux/macOS; no preconfigured personal data.
- Separate optional MCP account profile and collection-scoped login CRUD.
- Private initialization, inactive templates, discover, diagnostics and detailed help.
- Explicit-lock SSH sessions, load-all, statuses and direct OpenSSH socket handoff.
- Versioned encrypted v2 archives, verification, clean-home restoration and v1 reading.
- Manual connection-transfer procedure; no automatic migration or remote changes.
